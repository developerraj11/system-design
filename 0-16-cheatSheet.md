# 23. Your first revision cheat sheet

Keep this near you during preparation:

| Question | Quick Answer |
|---|---|
| Scalability | Handle increasing traffic |
| Vertical scaling | Bigger machine |
| Horizontal scaling | More machines |
| Load Balancer | Distributes traffic |
| Stateless | Any server can handle request |
| Redis | Fast in-memory cache |
| Cache hit | Data found in cache |
| Cache miss | Fetch from DB |
| Replication | Copies DB data |
| Sharding | Splits data across DB nodes |
| Index | Faster query |
| Kafka | Distributed event streaming |
| Queue | Async/background processing |
| Rate limiting | Protect APIs |
| Circuit breaker | Stop calling failing service |
| CDN | Serve static content near users |
| API Gateway | Single entry point for APIs |
| JWT | Stateless authentication token |
| MongoDB | Document-oriented DB |
| SQL | Relational/structured data |
| Availability | System remains accessible |
| Reliability | System performs correctly |
| Latency | Response time |
| Throughput | Requests processed per unit time |
