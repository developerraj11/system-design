

# 3. Pehla golden concept: Functional vs Non-Functional

Ye question almost har system design interview mein indirectly aata hai.

### Functional Requirements

System **kya karega?**

Example: URL Shortener

```text
1. User long URL submit kare
2. System short URL generate kare
3. Short URL open karne par original URL par redirect kare
```

### Non-Functional Requirements

System **kaise perform karega?**

```text
High availability
Low latency
Scalability
Reliability
Security
Consistency
Fault tolerance
```

### Interview answer

> **"Functional requirements define what the system should do, whereas non-functional requirements define how well the system should perform, for example scalability, availability, latency and security."**

### Memory trick

> **Functional = WHAT**  
> **Non-functional = HOW WELL**
