
# 22. One thing I want you to change

You told me you don't have practical System Design experience.

So **don't try to pretend that you have designed massive systems in production**.

If interviewer asks:

> "Have you designed this system?"

Use:

> "I haven't owned this exact system end-to-end in production, but based on my experience with React, Node.js, MongoDB and distributed application concepts, this is how I would approach the design."

Then explain confidently.

That's much better than getting trapped when they ask:

> "Why did you choose Kafka?"

> "Why MongoDB?"

> "Why Redis?"

> "What happens when Redis fails?"

Because now you're explaining **reasoning**, not claiming fake experience.
